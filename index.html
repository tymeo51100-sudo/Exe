Executor V1

La solution ultime pour vos scripts.

À propos

Bienvenue sur la page officielle de votre nouvel executor. Cet outil est conçu pour offrir une exécution fluide et sans interruption.

Comment l'utiliser ?

  1. Téléchargez le client.
  2. Lancez l'application en mode administrateur.
  3. Collez votre script dans l'éditeur ci-dessous.

Exemple de script

print("Initialisation du moteur...")
executor.run("load_script.lua")
print("Exécution terminée.")
